## Goal
Calculate each employee's monthly net salary from grade salary, department incentive, years-of-service incentive and attendance, and store frozen payslips per month (needed by the salary and incentives/deductions reports).

## Formula (all % applied to Basic — see Analysis BR-08/BR-09)
```
Basic            = grade salary effective for the month
DeptIncentive    = Basic × Department.IncentivePercentage
ServiceIncentive = Basic × matched service tier %
AttendanceBonus  = Basic × bonus % (0–1 absence days)
AbsenceDeduction = Basic × matched deduction %
Net              = max(0, Basic + DeptIncentive + ServiceIncentive + AttendanceBonus − AbsenceDeduction)
```
Rounding: 2 decimals, `MidpointRounding.AwayFromZero`.

## Lifecycle
`Draft` (can recalculate) → `Approved` (frozen; Admin only).

title: [Backend] Payroll runs: generate, recalculate, approve + payslip snapshots
labels: type:task, area:backend, module:payroll, priority:high
---
## Description
Generate monthly payroll for all active employees and persist results.

## Technical Details
- Entities:
  - `PayrollRun : AuditableEntity { int Year, int Month, PayrollStatus Status (Draft/Approved), DateTime? ApprovedAt, int? ApprovedBy, decimal TotalNet, int EmployeesCount }`; unique `(Year, Month)`.
  - `Payslip { PayrollRunId, EmployeeId, EmployeeNameAr, EmployeeNameEn, DepartmentNameAr, DepartmentNameEn, Grade, YearsOfService, AbsenceDays, Basic, DeptIncentivePct, DeptIncentive, ServiceIncentivePct, ServiceIncentive, AttendanceBonusPct, AttendanceBonus, AbsenceDeductionPct, AbsenceDeduction, Net }` — denormalised snapshot.
- Endpoints (`/api/v1/payroll/runs`):
  - `POST` `{ year, month }` → creates Draft and calculates (HrOrAdmin); 409 if exists.
  - `GET` (paged, by year), `GET /{id}` (with payslips, filter department, paging), `GET /{id}/payslips/{employeeId}`.
  - `POST /{id}/recalculate` (Draft only) — re-reads current data.
  - `POST /{id}/approve` (AdminOnly) — freezes; locks attendance month and used grade salaries.
  - `DELETE /{id}` (Draft only, Admin).
- Employees included: not deleted and `HireDate <= month end`.
- Run inside a transaction; performance target: 1,000 employees < 3 s.

## Acceptance Criteria
- [ ] Draft can be regenerated; Approved cannot be changed (409).
- [ ] Changing rates after approval does not change stored payslips (integration test).
- [ ] Totals on the run equal the sum of payslips.

**Estimate:** 5 SP
